# albertmata.net

Source code for my personal website, built with plain HTML, CSS and JavaScript and published with GitHub Pages.

Pages live under `/ca/` (Catalan) and `/en/` (English), with matching `profile/` and `privacy/` sections. Update both language versions when changing content. Shared styles and scripts live in `assets/`.

The root redirects to `/ca/`. Legacy `/profile/` and `/privacy/` URLs redirect to their English equivalents. `/cv/`, `/ca/cv/` and `/en/cv/` point to the existing CV PDF; the PDF is not localized.

Each content page includes a language selector, its own canonical URL and alternate language links. Keep `sitemap.xml` in sync when adding pages.
